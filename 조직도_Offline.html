0. 메뉴 구성

  • 파일 — 저장(브라우저) · 배치파일 저장(pic 폴더용) · pic 폴더에서 불러오기 · JSON 내보내기/불러오기 · 이미지 저장(PNG) · 용지 선택 · 인쇄/PDF
  • 편집 — 실행취소·다시실행 · 박스 추가 · 복사/붙여넣기/복제 · 위치 전체초기화
  • 보기 — 사진·업무분장표·인원현황표 표시 · 모두 펼침 · 확대/축소/100%
  • 사진 — 사진폴더 지정 · 사진 불러오기 · 사진 갱신
  • 도움말 — 지금 보고 있는 사용안내
  • 메뉴 오른쪽에는 제목 · 작성일자 · 총원 이, 맨 오른쪽에는 확대/축소와 저장 버튼이 항상 보입니다.

1. 기본 조작

  • 박스를 클릭하면 선택(주황 테두리), 더블클릭하면 편집창이 열립니다.
  • 선택 해제 : 저장 버튼 · 캔버스 빈 곳 클릭 · ESC
  • 화면 확대·축소는 오른쪽 － / ＋ 버튼 또는 보기 메뉴를 사용합니다.

2. 박스 추가·삭제

  • 편집 ▸ ＋ 인원 박스 추가 : 선택한 박스 아래에 인원 박스를 추가합니다. 인원 박스는 사진·직급·성명·사번 3행으로 표시됩니다.
  • 편집 ▸ ＋ 업무 박스 추가 : 선택한 박스 아래에 주업무 박스를 추가합니다. 사진·성명이 없고 업무명과 업무내용만 표시됩니다.
  • 편집창의 ＋하위인원 / ＋하위업무 / ＋동급인원 / ＋동급업무 로도 추가할 수 있습니다.
  • 종류전환 : 인원 박스 ↔ 업무 박스를 서로 바꿉니다.
  • 삭제는 편집창의 삭제 버튼 또는 Delete 키 (하위 박스가 함께 삭제됩니다).

3. 복사 · 붙여넣기

  • 복사 Ctrl+C : 선택한 박스를 하위 박스까지 통째로 복사합니다.
  • 붙여넣기 Ctrl+V : 선택한 박스의 하위로 붙여넣습니다.
  • 동급붙임 Ctrl+Shift+V : 선택한 박스와 동급(형제)으로 붙여넣습니다.
  • 복제 Ctrl+D : 선택한 박스를 바로 옆에 동급으로 복제합니다.
  • 복사본은 사진·직급·성명·사번·업무내용·그룹 설정까지 그대로 따라오며, 자유 이동 위치만 초기화됩니다.
  • 편집창이 열려 있을 때의 Ctrl+V 는 사진 붙여넣기로 동작합니다. 박스를 붙여넣으려면 편집창을 닫고(ESC) 누르세요.

4. 위치 이동

  • 박스를 끌어 다른 박스 위에 놓으면 그 박스의 하위로 이동합니다.
  • 박스의 좌·우 가장자리에 놓으면 앞/뒤 형제로 순서가 바뀝니다.
  • 상위선택 : 편집창에서 누른 뒤 상위가 될 박스를 클릭하면 그 아래로 연결됩니다. 수평 관계를 하위 관계로 바꿀 때 사용합니다. ESC 로 취소합니다.
  • 박스를 0.4초 이상 길게 누르면 상하좌우 자유 이동이 됩니다. 이동 중 좌측·상단 모서리 기준 참조선이 표시되고, 다른 박스 모서리에 6px 이내로 가까워지면 주황색 선과 함께 자동으로 정렬됩니다.
  • 모든 박스 위치와 연결선은 2px 격자에 맞춰집니다.

5. 연결선 조정

  • 선＋ / 선－ : 상위 박스와의 연결선 길이를 8px 단위로 조절합니다.
  • 행↓ / 행↑ : 박스를 한 행 단위로 내리거나 올립니다.
  • 수직정렬 : 상위 박스와 같은 수직축에 맞춥니다. 멀리 이동하면 자동으로 화면을 옮겨 깜빡입니다.
  • 위치초기화 (해당 박스) / 위치 전체초기화 (전체 + 인원현황 표)

6. 묶음 배치

  • 그룹 : 하위 박스를 하나의 상자에 격자로 묶습니다. 상자 안쪽에는 연결선이 없고, 상위 박스에서 상자 윗변까지 한 줄만 연결됩니다. 열＋ / 열－ 로 가로 개수(1~8열)를 정하고, 다른 박스를 상자 안으로 끌어다 놓으면 그룹에 들어갑니다.
  • 세로배치 : 상위 박스 중앙에서 내려오는 세로선에 하위를 매답니다. 하위가 없는 박스에서 누르면 그 상위에 적용됩니다.
  • 그룹과 세로배치는 동시에 적용되지 않습니다.

7. 사진

  • 편집창의 사진 선택(파일), 사진 붙여넣기(클립보드 버튼), 또는 편집창이 열린 상태에서 Ctrl+V 로 등록합니다.
  • 붙여넣은 뒤 반드시 적용을 눌러야 조직도에 반영됩니다.
  • 120×150 크기로 자동 축소·JPEG 압축(장당 약 10KB)되어 조직도와 함께 저장됩니다.
  • 보기 ▸ 사진 표시 체크를 끄면 모든 사진이 숨겨집니다.

8. 업무분장표

  • 편집창 업무내용에 한 줄에 한 항목씩 입력합니다.
  • 업무 박스에는 상자 안에, 조직도 하단 업무분장표에는 인원별로 번호가 매겨져 표시됩니다.
  • 업무분장표의 행을 클릭하면 해당 박스로 이동하고, 더블클릭하면 편집창이 열립니다.
  • 보기 ▸ 업무분장표 표시 체크로 표를 숨길 수 있습니다.

9. 인원현황 표

  • 조직도 좌측 하단에 있습니다. 숫자 칸과 열 이름을 클릭해 바로 입력하며 합계는 자동 계산됩니다.
  • ＋열 / －열 로 구분 항목을 추가·삭제합니다.
  • 입력칸이 아닌 곳(제목·머리글 등)을 끌어서 표 위치를 이동할 수 있습니다.
  • 표 우측 하단의 크기 손잡이를 끌면 표 크기가 50~300%로 조절됩니다. 손잡이를 두 번 클릭하면 100%로 돌아가고, 표＋ / 표－ 버튼으로도 조절됩니다.
  • 보기 ▸ 인원현황표 표시 체크로 숨길 수 있습니다.

10. 제목

  • 조직도 상단 제목을 더블클릭하면 그 자리에서 수정할 수 있습니다. Enter 로 확정, ESC 로 취소합니다.
  • 제목 영역을 끌어서 위치를 옮길 수 있습니다. (상단 제목 입력칸으로도 수정 가능)

11. 사진 넣기 · pic 폴더 (오프라인)

  • HTML 파일 옆에 pic 폴더를 만들고 그 안에 사진을 넣으면 자동으로 표시됩니다. 파일 이름은 사번 또는 성명.
    예) pic/930615.jpg · pic/천남이.jpg · pic/천남이_930615.jpg · pic/천남이(930615).png
  • 확장자는 jpg · png · jpeg, 찾는 순서는 사번 → 성명 → 성명_사번 → 성명(사번) 입니다.
  • 동명이인은 성명_사번 형식으로 지어야 정확히 구분됩니다.
  • 폴더 이름을 바꾸려면 사진 ▸ 사진폴더 칸을 고치고, 파일을 교체했으면 사진 ▸ ↻ 사진 갱신 을 누르세요.
  • 사진 ▸ 📁 사진 불러오기 로 사진들을 한 번에 선택하면 파일명으로 매칭해 조직도 안에 담습니다(120×150 축소). 이렇게 하면 사진 파일 없이도 열리고 이미지저장·배치파일 에도 사진이 함께 들어가므로 권장합니다. 창에 파일을 끌어다 놓아도 동일합니다.

12. 저장·출력

  • 파일 ▸ 저장 Ctrl+S : 이 컴퓨터 브라우저에 저장됩니다. 같은 PC·같은 브라우저에서만 유지됩니다.
  • 파일 ▸ 📦 배치파일 저장 : 조직도_data.js 를 내려받아 pic 폴더에 넣어두면, 다음에 HTML 을 열 때 배치·사진이 자동으로 적용됩니다. 폴더째 복사하면 다른 PC 에서도 그대로 열립니다.
  • 파일 ▸ 📂 pic 폴더에서 불러오기 : 편집 중인 내용을 버리고 pic 폴더의 배치파일 상태로 되돌립니다.
  • 인터넷·서버 연결이 전혀 필요 없는 오프라인 전용 파일입니다.
  • ⇩ JSON 으로 파일 내보내기, ⇧ JSON 으로 불러오기 (불러온 뒤 저장해야 반영됩니다).
  • 🖼 이미지저장 : 조직도 전체를 PNG 이미지로 저장합니다. 화면에 보이는 그대로(연결선 포함) 2배 해상도로 저장되므로, 인쇄나 문서 삽입에는 이 방법을 권장합니다.
  • 인쇄/PDF : 용지(A4·A3, 가로·세로)를 고른 뒤 실행합니다. 빈 여백을 뺀 실제 조직도 영역만 계산해 용지에 꽉 차도록 자동 확대·축소하고 가운데 정렬합니다.
  • 인쇄창을 닫거나 취소하면 편집 화면과 스크롤 위치가 그대로 복구됩니다.
